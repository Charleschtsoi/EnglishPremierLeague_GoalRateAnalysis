# Premier League Match Analysis: Clustering & Predictive Insights

Advanced clustering analysis of English Premier League matches to identify tactical patterns and their predictive value for goal scoring.

## Project Overview

This project applies unsupervised clustering to 9,300+ Premier League matches (2000/01 onwards) to discover hidden match archetypes and evaluate whether they improve goal prediction beyond traditional match statistics.
